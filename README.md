# Github-guide

나의 첫 깃허브 공부 기록입니다. 마크다운(Markdown)을 활용해 정리해 보았습니다.

## 📝 마크다운(Markdown) 기초 문법
테이블을 사용해 주요 문법을 정리했습니다.

| 문법 | 설명 | 예시 |
| :-- | :-- | :-- |
| `#` | 제목 (Heading) | `# 큰 제목`, `## 중간 제목` |
| `** **` | 굵게 (Bold) | **텍스트** |
| `* *` | 기울임 (Italic) | *텍스트* |
| `[ ]( )` | 링크 (Link) | [네이버](https://naver.com) |
| `-` 또는 `*` | 글머리 기호 | - 리스트 아이템 |
| `> ` | 인용문 | > 인용구 작성 |
| `` ` ` `` | 코드 강조 (Inline) | `print("Hello")` |

---

## 🛠 깃허브 핵심 용어
초보자가 꼭 알아야 할 3가지 개념입니다.

1. **Commit (커밋):** 현재 작업 내용을 저장소에 저장하는 것 (저장 시점의 스냅샷)
2. **Push (푸시):** 내 컴퓨터에서 작업한 내용을 온라인 깃허브 저장소로 올리는 것
3. **Pull (풀):** 온라인 깃허브 저장소의 최신 내용을 내 컴퓨터로 가져오는 것
